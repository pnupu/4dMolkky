Agent evidence contract

Build evidence
Every candidate gets a manifest with version, build command, tests, known issues, SHA-256, screenshots, video, platform, and controls.
Unity operation
Prefer batch-mode editor commands and a standalone autoplay demo. The macOS Unity Editor has no dependable computer-control MCP in this setup.
Video recording
Launch the standalone player, run a deterministic demo, record a bounded interval with macOS screencapture, and store the original MOV under artifacts/videos.
Agent update format
STATE · DONE · EVIDENCE · BLOCKER · NEXT · DECIDE BY. Keep it short enough to review from a phone.
Automatic cuts
Phone optional after Friday 23:30 if not end-to-end. No VR without a proven device path. No new systems after Saturday 21:00. Blocker fixes only after Sunday 14:00.
